# Текущая задача

- **Цель:** интегрировать безопасный Testnet/read-only runtime с текущими
  исправлениями, устранить найденные дефекты и подтвердить качество полным
  набором проверок.
- **Статус:** выполнено 2026-08-27.

## Критерии готовности

- [x] Read-only market loop, публичный WebSocket, SQLite и paper trading
  интегрированы без включения реальных заявок.
- [x] Сохранены проверки конфигурации, risk manager и защита от параллельных
  ордеров в executor.
- [x] Исправлены Bybit position/leverage endpoint и поле времени позиции по
  актуальному официальному V5-контракту.
- [x] Документация соответствует фактическому коду и базовому CI.
- [x] Форматирование, unit-тесты, race detector, `go vet`, vulnerability scan и
  сборка успешны.

## Вне задачи

Реальная отправка/закрытие заявок, восстановление позиций после перезапуска и
неопределённые execution-policy остаются заблокированы открытыми решениями из
`docs/DECISIONS.md`.
