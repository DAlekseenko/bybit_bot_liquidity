# Текущая задача

- **Цель:** реализовать первый инкремент `internal/exchange/bybit` — публичные
  REST-методы свечей и open interest без приватной торговли.
- **Статус:** выполнено 2026-07-22.
- **Следующая задача:** не назначена (`TODO`: выбрать следующий инкремент после
  public market data).

## Критерии готовности

- [x] Контракты сверены с актуальной официальной документацией Bybit V5.
- [x] `GetCandles` запрашивает linear 1m kline, проверяет ответ и возвращает свечи
  в хронологическом порядке.
- [x] `GetOpenInterest` запрашивает последнее linear OI с минимальным доступным
  интервалом `5min`.
- [x] Ошибки входа, HTTP, Bybit `retCode`, JSON и пустых результатов различимы и
  покрыты unit-тестами без реального API.
- [x] Приватные методы сохраняют явный `ErrNotImplemented`.
- [x] API/архитектура/context/handoff отражают новый фактический статус.
- [x] Пройдены `gofmt`, unit-тесты, race detector, `go vet`, сборка и проверка
  Markdown-ссылок.

3. Добавить тесты успешных ответов, валидации и ошибок границ.
4. Обновить только затронутые источники документации.
