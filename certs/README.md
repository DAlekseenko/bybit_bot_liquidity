# Дополнительные локальные CA

Каталог монтируется в контейнер read-only и предназначен только для
дополнительного корневого сертификата корпоративного TLS proxy.

Обычный интернет-доступ не требует файлов в этом каталоге. Если Docker получает
ошибку `x509: certificate signed by unknown authority`, экспортируйте публичный
CA вашей организации в `certs/local-ca.pem`. Файлы `*.pem`, `*.crt` и `*.cer`
исключены из Git и Docker build context.

Не размещайте здесь private keys или клиентские сертификаты.
