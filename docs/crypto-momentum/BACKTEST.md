# Офлайн-бэктест

Команда повторно вычисляет офлайн baseline из замороженного датасета и
канонической модели. Она не читает credentials/DSN, не обращается к бирже и не
даёт полномочий на торговлю или deployment.

```sh
momentum backtest -config configs/backtest.yaml -dataset ./frozen -model ./model.json \
  -start 2025-07-07T00:00:00Z -end 2025-07-08T00:00:00Z \
  -approval audit/offline-run/123 -output ./runs/run-123
```

Нужны все флаги: конфигурация с `mode: backtest`, папка замороженного датасета,
снимок модели, RFC3339Nano начало и конец (начало строго раньше конца), стабильная
строка `-approval` для аудита и выходная папка. Конфигурация должна совпадать с
manifest/dataset/model pins; загрузчик проверяет их до расчёта. Родитель `-output`
должен существовать. Каждый запуск заново рассчитывает результат; совпадающий
полный результат в существующей папке проверяется штатным writer как idempotent.

Успех печатает детерминированный RunID и публикует ровно шесть файлов:
`config.json`, `journal.json`, `run.json`, `simulation-model.json`,
`source-manifest.json`, `SHA256SUMS`. Ошибка stdout возвращается после публикации,
поэтому полная папка результата может уже существовать. Неизвестные, недоступные
или отключённые величины остаются такими в отчёте; команда не подменяет их нулями.
