# CM-003B — неизменяемый TradePlan

`TradePlan` фиксирует проверенный `PortfolioSnapshot`, переданные вызывающей
стороной цели и метаданные ревизии. Модель не выбирает цели, не вычисляет
бюджеты или риск, не выполняет I/O и не разрешает исполнение.

`NewTradePlan` fail-closed проверяет snapshot и совпадение его SHA-256, пять
обязательных ID, 64 строчных hex-символа `ConfigHash`, времена, формат ссылки
ревизии, валидность/неотрицательность количества, уникальность непустых
символов и наличие цены каждого символа в snapshot. Времена нормализуются в
UTC. Цели сортируются по символу и копируются; read methods возвращают значения
или копии.

Hash версии `momentum/trade-plan/v1` включает hash snapshot, все метаданные и
отсортированные цели. Строки имеют длиновые границы, а количество кодируется
точным `Decimal.CanonicalRatio()`, поэтому рациональные значения, включая `1/3`,
не округляются. Новая ревизия — новый объект со ссылкой на hash предыдущей;
проверку непрерывности цепочки и уникальности run key выполняет durable storage.

`ConfigHash` относится к подготовленному безопасному снимку конфигурации; сырые
настройки и секреты не передаются модели. D-01 остаётся открытым: сохранённые
targets не утверждают baseline формулу, equity cutoff или резерв. Торговый
transport, подтверждение и исполнение в эту модель не входят.
